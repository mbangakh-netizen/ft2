1. Open api/image.js.
2. Replace PASTE_YOUR_LONG_FACEBOOK_IMAGE_URL_HERE with the full Facebook image URL.
3. Upload these files to GitHub.
4. Import the repository into Vercel and deploy.
5. Use https://YOUR-APP.vercel.app/api/image as the image URL.

Note: this proxies the image; it does not make an expiring Facebook CDN URL permanent.
